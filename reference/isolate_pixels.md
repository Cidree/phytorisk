# (Internal) Isolate pixels

(Internal) Isolate pixels

## Usage

``` r
isolate_pixels(flowdir, dem, init_i, init_j)
```

## Arguments

- flowdir:

  a `SpatRaser` with the flow directions

- dem:

  a `SpatRaster` with a digital elevation model

- init_i:

  ith row to start

- init_j:

  jth column to stat

## Value

a SpatRaster
