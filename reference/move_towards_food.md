# (Internal) Move animals towards food

Moves animals towards a food source specified in pixels based on
randomness

## Usage

``` r
move_towards_food(animal, food_coords, pixel_size, exclusion_area_sf)
```

## Arguments

- animal:

  location of the animal

- food_coords:

  coordinates of food

- pixel_size:

  size of the pixel

- exclusion_area_sf:

  area of exclusion

## Value

a new animal
